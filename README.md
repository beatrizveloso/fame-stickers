# 🎴 Fame Stickers

Fame Stickers é um joguinho de adivinhação inspirado em figurinhas de álbum da Copa, mas com celebridades! ⭐

O jogador precisa descobrir qual famoso está escondido na figurinha borrada usando dicas como:

* 🌍 País de origem
* 🎤 Profissão
* 💬 Frase icônica

Quanto menos dicas usar, mais pontos ganha.

## 🚀 Tecnologias

* HTML
* CSS
* JavaScript

## 🏆 Sistema de Pontuação

A pontuação depende da quantidade de dicas utilizadas:

* ⭐ 100 pontos → sem usar dicas
* ⭐ 70 pontos → usando 1 dica
* ⭐ 40 pontos → usando 2 dicas
* ⭐ 10 pontos → usando 3 dicas

O objetivo é acertar o famoso com o menor número possível de dicas para conseguir mais pontos.

## ✨ Funcionalidades

* Sistema de dicas
* Pontuação
* Figurinhas borradas/pixeladas
* Aceita respostas com ou sem acento
* Visual inspirado em álbum de figurinhas/Y2K
